# Ganesh Anil Patil Books — refreshed frontend

## Files
- `index.html` — homepage, book catalogue, blog section, author/contact and privacy note
- `styles.css` — responsive design, mobile navigation, dark mode and modals
- `app.js` — book search/filters, Google Play Books purchase link, article popups, language toggle and dark mode

## Publish on GitHub Pages
1. Download and unzip this package.
2. Open your `Gbook` repository on GitHub.
3. Upload/replace `index.html`, `styles.css`, `app.js`, and `README.md` in the repository root.
4. Commit the changes and wait for GitHub Pages to redeploy.
5. Open the website and hard-refresh if the old version is cached.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with a public author email, or remove the email button.
- Blog articles are starter examples; revise them in your own voice before publishing.
- The newsletter/backend, admin panel, login, database, and live analytics are not connected. Do not put passwords or API keys in these files.
- This is a static frontend. Book/blog content is edited by changing the HTML/JavaScript files; it does not yet have a secure admin dashboard.
